## 📱 About The Project

**ID Melk App** is a real estate mobile application frontend developed using **Flutter**.

This project was designed based on the client's requirements and preferred visual style to create a modern and user-friendly interface for a real estate platform.

🚀 Features:
- 🏠 Real estate application UI
- 🎨 UI design based on client's preferences
- 📱 Responsive mobile interface
- ⚡ Developed with Flutter

### ⚠️ Project Status

This project was discontinued due to the cancellation of the main project by the client.

Only the **frontend/UI part** of the application was completed, and backend integration was not implemented.

# 🏠 اپلیکیشن آیدی ملک

## 📱 درباره پروژه

**اپلیکیشن آیدی ملک** یک اپلیکیشن موبایل در حوزه املاک است که بخش رابط کاربری آن با استفاده از **Flutter** توسعه داده شده است.

طراحی ظاهری اپلیکیشن بر اساس **نیازها، درخواست‌ها و سلیقه کارفرما** پیاده‌سازی شده و هدف آن ایجاد یک تجربه کاربری مدرن برای یک پلتفرم املاک بوده است.

✨ امکانات:
- 🏠 طراحی رابط کاربری اپلیکیشن املاک
- 🎨 پیاده‌سازی ظاهر برنامه مطابق با نظر کارفرما
- 📱 طراحی واکنش‌گرا برای موبایل
- ⚡ توسعه داده شده با Flutter

### ⚠️ وضعیت پروژه

به دلیل لغو شدن پروژه اصلی توسط کارفرما، ادامه توسعه پروژه متوقف شد.

در این ریپازیتوری فقط **بخش فرانت‌اند و رابط کاربری اپلیکیشن** قرار داده شده و بخش بک‌اند و اتصال به سرور پیاده‌سازی نشده است.
